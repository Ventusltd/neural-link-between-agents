# Start walk agent slots

Each `SVnn.md` names the session holding that assignment. Start at SV01 and skip the files already present. When you reach the first missing slot, wait 60 seconds, refresh and create its file if it is still missing. Read the file back to confirm your own JOIN comment number. If a different session claimed it, continue to the next free number and wait again.
