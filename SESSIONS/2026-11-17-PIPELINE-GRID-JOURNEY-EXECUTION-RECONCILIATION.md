## 3. Grid Journey baseline: topology is not a surveyed cable route

The pinned ETYS network contains 921 sites, 2,679 nodes, 1,392 circuit **rows**,
1,472 transformer **rows** and 2,230 planned changes. Connection points v3 has
886 sites: 489 located by automated joins (450 exact-name, 39 distinctive-token)
and 397 unlocated. Located is not independently reviewed identity; ambiguity
categories are not additive new sites outside that population.

The three inspected legacy voltage line layers contain GIS LineStrings but no
ETYS circuit/node identity fields. Mapped geography alone does not establish a
verified circuit/polyline join. Do not create connectivity from nearest sites,
line crossings, shared coordinates or a visually touching pair of voltages.
The inspected 132/275/400 kV layers contain 6,227/2,935/4,106 LineStrings,
respectively; these are mapped-feature counts, not accepted circuit counts.

The graph API already creates two landing wrappers for each source row, both
referencing that same row object. Recognise those wrappers as one source-row
edge. Preserve repeated input rows and parallel candidates without claiming
that each repeated row is an independently established physical unit. Source
products lack stable equipment IDs/original workbook row locators sufficient
to settle every multiplicity question. A reproducible provisional edge UID is
`bundle digest + kind + source-array index`, with row digest and review state
recorded separately; indices remain meaningful only within that exact bundle.
Never deduplicate source rows solely by endpoint pair or complete row content.

The audit found **726 nodes with untrusted/undeclared voltage**, 76 circuit rows
and 690 transformer rows with at least one undeclared endpoint. Current BFS
rejects a circuit between two declared unequal voltages, but allows unknown
voltage because a crossing is not proven. A Journey policy must classify/refuse
insufficient voltage evidence explicitly. Leave `between()` and `within()`
unchanged. An explicit transformer row is necessary, but its unresolved identity
or endpoints still require review; co-location never creates a transformer.

Rights gate: the data-owner README explicitly says applicability of NESO's open
licence to the ETYS appendices is still being confirmed. A general licence page
does not establish a dataset-specific grant. OSM geometry retains its own ODbL
attribution/share-alike basis; an OS source requires its own exact product terms.
Do not promote research-only diagrams, literature or blocked geometry into an
accepted input manifest. Follow the original five evidence classes; unknowns
and refused joins remain in coverage reports.

Primary terms references: [NESO dataset-specific licence](https://www.neso.energy/data-portal/neso-open-licence),
[OSM copyright/ODbL](https://www.openstreetmap.org/copyright), and
[OS OpenData](https://www.ordnancesurvey.co.uk/products/open-data).
