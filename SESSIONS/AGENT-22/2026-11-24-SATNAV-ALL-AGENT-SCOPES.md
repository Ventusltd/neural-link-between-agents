## Milestone 2 — independent build in parallel

On the existing GridAtlas map/satellite host, select a bounded transmission-line segment or continuous section. Render the measured GPS dot and accuracy circle at actual fix; a separate marker identifies nearest point on selected geometry. Show approximate lateral distance and progress only for a clearly oriented continuous section; endpoints clamp, ambiguity/poor/stale fixes visible. Never snap the measured position, invent a line identity, infer rights of access, or imply the line is a route. Optional explicit target handoff uses milestone 1. No LiDAR, terrain, new map engine, turn-by-turn, road/off-road routing, offline packs or GPU dependency in either milestone.
