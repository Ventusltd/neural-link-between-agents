## Shared module contract v1
Python 3.12 target, Windows MSI and Linux CI. pathlib, UTF-8, pinned dependencies, no hardcoded paths, driver installs or admin changes. Each module CLI accepts --config PATH --run-dir PATH --input-dir PATH --output-dir PATH; --self-test runs tiny offline fixtures. Exit 0 success/no-op, 2 invalid config/data, 3 retryable limit/resource failure. Atomic output and JSON manifest with schema_version, stage, run_id, input hashes, output relative filenames/SHA256, row counts, elapsed time, status, warnings and parser/model versions. Reject path traversal and untrusted instructions embedded in code; no arbitrary source execution. Stable identity, idempotent checkpoints, preserve last good snapshot. Keep exact model outputs; do not claim nondeterministic prose is reproducible.
Config: source_manifest, read-only local source_root, state_dir, run_id, max_new_unique_lines (aggregate optional, no artificial local daily cap), max_wall_seconds (owner-launched overnight ceiling 12h), max_memory_mib, max_vram_mib, max_model_tokens, max_paid_model_cost (default zero unless approved), provider=offline_rule_based|local_model|codex_connected, publish=false, gpu=auto|cpu|cupy. Set measured hardware limits at preflight. No circumventing account limits.

Logical Parquet tables:
- source_lines: canonical Kuiper ID where available, otherwise provisional content hash with normalization version; exact digest, language, classification, status.
- occurrences: stable occurrence ID or provisional repo+commit+path+line, line ID, blob hash, rights.
- functions: stable ID, exact spans/hashes, language, English title/purpose, inputs, outputs, side effects, dependencies.
- line_function_links: line ID, occurrence ID, function ID, contextual role.
- meanings: target ID, contextual English, evidence, method/version, source hash, status/review flags.
- verification: meaning ID, structural/semantic status, evidence, flags.
- packages: function ID, existing package reference/version, typed inputs/outputs, admission, rights, limitations.
- runs: counts/checkpoints/hashes/limits/errors.
Explicit schemas, nullable unknowns, stable keys, preserve identical text in different contexts. Distinguish unique lines from historical occurrences; record comments, whitespace, generated/excluded files according to documented canonical counting policy. No fabricated meanings or coverage. Freeze measured initial inventory; separate changes. Filter source, descriptions, metadata and secrets by rights before public export.
