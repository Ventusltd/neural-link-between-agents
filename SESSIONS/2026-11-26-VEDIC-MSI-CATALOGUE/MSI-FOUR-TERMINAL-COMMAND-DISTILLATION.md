## Definition of one command
One short canonical human-readable imperative expressing a coherent operation or major reusable function (e.g. ORIENT, MEASURE DISTANCE, FIND NEAREST SUBSTATION, FILTER PROJECTS). These are illustrative names, not claims of new admissions. Prefer a single word if unambiguous; use a short phrase if necessary. Associate aliases and multiple implementations with an existing canonical command when semantics match. Different behaviour, units, preconditions, side effects or error contracts may require a distinct operation or explicit variant. A source function, line, AST node, alias, occurrence, package or prose paragraph is not automatically a command. Record existing identity, canonical label, one-line meaning, typed inputs and outputs where known, applicability, dependencies, exact pinned source evidence, review/execution status, and limitations. No fabricated permanent identifiers or source coverage. Reuse existing schema and permanent IDs; assign deterministic candidate IDs only within existing policy.
