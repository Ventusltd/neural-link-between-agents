## Merchant of Venice bookkeeping convention
One principal (specific claim, version and input scope) opens one debit for each independently testable obligation. A matching measured twin is a credit only for the SAME obligation, exact head/fixture, scope and criterion, with a named test and independent reviewer verdict. A negative finding is a dispute, never a credit. Partial or historical evidence is linked but cannot close a current broader claim. No fungibility across obligation types; a hundred static checks cannot pay one missing runtime test. No monetary or quantum probability units.
Proposed consumer receipt fields: schema; ledger_id (local receipt ID, not a permanent VEDIC ID); principal; obligation_id; claim_head; target source (repo/commit/path/blob/span, ordered line IDs, element/family IDs or null); periodic category/block plus basis and status; Kuiper receipt/digest or null; Spider edge type/snapshot; input fixture and digest; acceptance criterion; twin observation with test command/result/observed head/evidence URL; positron test and outcome; witness lens/declared role/verdict/evidence URL; state OPEN/PARTIAL/DISPUTED/SETTLED; supersedes; recorded_at and observed_at. Hash canonical JSON bytes, append corrections rather than silently replace; evidence provenance is not authenticated merely by hashing it. One integrator owns ledger writes; agents submit receipts in NL-087; preserve original links. Same account labels do not prove independence; actual separate replay and provenance are required. Deduplicate by obligation identity and artifact digest; same artifact may support distinct criteria only with explicit named assertions. Reopen on changed source/fixture/contract, don't inherit prior green. No automatic promotion.
Closing invariant: all required obligations settled, zero unresolved disputes, independent review at the exact integration head, owner approval for release. Report balances by obligation, not combined percentages of estate coverage. Unique line count uses set union of permanent line IDs at pinned producer snapshot.
