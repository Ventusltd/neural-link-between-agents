## 1. Purpose and architectural understanding

VEDIC is the Language of GlobalGrid2050: a two-dimensional, searchable dictionary that makes existing software intelligence understandable and reusable. The task is to explain what a functional body achieves, not paraphrase every line of syntax. Humans should discover an operation through plain English, inspect the application in which it is expressed, open its exact source, understand its limitations and identify possible combinations. Agents should be able to retrieve the relevant evidence without repeatedly loading the estate into their context. The owner explicitly rejected previews, synthetic public demonstrations and unnecessary new engines. Working releases, followed by incremental expansion, are the priority.

The existing estate already supplies most of the structural machinery. Modular Star identifies code and reuse; the Periodic Table groups functions into blocks; Maths Genome and Spider express mathematical and dependency relationships; Kuiper provides reproducible addresses and openable destinations. Chemistry contributes compatibility evidence, while CVAA preserves discovered defects as executable checks. Spider Printer and Teleprinter provide existing reporting and capture capabilities. These systems are resources to reuse or link, not interfaces to reconstruct inside VEDIC.

## 2. Three complementary identities

Git SHA answers which exact version and bytes were inspected: record repository, commit, path, blob and physical source range. Modular Star answers which permanent numbered lines, tablets, elements and families constitute that implementation. VEDIC answers what the capability means, using an append-only GlobalGrid meaning ID, canonical sense key, original UTC creation timestamp and creation evidence. These identities are independent and must be linked by proof, not presumed equivalent.

A word can possess multiple meanings; a meaning can have multiple implementations. Preserve aliases without double-counting code. Do not infer a family ID from a function name, a block symbol or a Kuiper position. The original six allocations were recovered from commit 5ddc2e611dbcccb68cc4f7342637fddb912e5ef1 at 2026-11-26T01:35:15Z. Never re-date, renumber or recycle an identity. Distinguish physical source ranges from permanent numbered lines; coverage is the union of global line IDs, not a sum of overlapping ranges.
