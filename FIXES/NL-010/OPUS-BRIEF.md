- Lead: owns the module file and the hand-off; writes the module's skeleton first (within 10 minutes) so the others
  have a target; merges the builder's work; posts the team's HANDOFF comment on issue #10 when test.cjs passes.
- Builder: works in the SAME module file after the lead's skeleton exists (poll for it), on the parts the lead names in
  handoff/NN-<name>/PLAN.md; never a second module file.
- Tester: writes test.cjs from the step's acceptance test, runs it against the module as it grows, writes the
  screenshots, and refuses the hand-off until it passes on both devices with zero console errors.
- Evidence officer: writes EVIDENCE.md (a key for every GridAtlas lesson and every Kuiper hook the module uses),
  LICENCE.txt, the header licence line, and reviews the lead's HANDOFF comment before it is posted.
