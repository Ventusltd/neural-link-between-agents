## How to read a row

- **time (UTC)**: `gh` is GitHub's `created_at` for a comment, or `merged_at` for a PR. `c` is the committer time of the
  first commit that holds the text. `f` is an in-file stamp that is not yet committed. A stamp written in a message that
  disagrees with the real time is flagged "stamp ahead/behind".
- **key**: `#10/6566796733` means
  `https://github.com/Ventusltd/neural-link-between-agents/issues/10#issuecomment-6566796733`. `kb` is kuiper-belt, `nl`
  is this repository, and `H/` is `kuiper-belt/editions/202611012135/handoff/`. Other repositories are named in full.
- **link**: `yes` means the decision was posted on the link when it was made. `late hh:mm` means it was acted on first
  and posted at that time. **`DM-ONLY`** means it was made by direct message (chat between the owner and the harness, or
  harness to subagent) and **has never been posted on the link**. `FILE-ONLY` means it was written in a repository file
  but never posted as a comment. `off-link` means it was posted on GitHub but outside #6–#11.
- **status**: `in force`, `superseded by Dnn`, `resolved by Dnn` (a refusal whose cause was fixed), or `open`.
